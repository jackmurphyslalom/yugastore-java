# Architecture Decision Records

Create an ADR only when all three conditions hold:

1. the decision is hard to reverse;
2. the result would be surprising without context;
3. a genuine tradeoff led to the selection.

If any condition is absent, keep the rationale in the relevant specification, plan, task, or documentation. Automated bootstrap never creates ADRs. Existing ADRs remain unchanged.

Use `template.md` and sequential names such as `0001-short-title.md`.
