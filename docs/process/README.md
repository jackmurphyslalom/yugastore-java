# Delivery Process

This directory holds project-owned process guidance that applies across features. Keep it short,
evidence-based, and linked from the commands or skills that use it.

- [`pr-process.md`](pr-process.md) defines the prepare-before-review handoff, comparison-base
  policy, and external-write boundary.

Feature-specific delivery notes remain under `specs/<feature>/`; do not copy them here unless the
rule applies to future work.
