# Reference Board Prompts

Use these prompts only to create internal inspiration boards or contact sheets from curated real deck renders. The boards help agents critique and learn visual rhythm; they are not official brand assets.

## Guardrails For Every Board Prompt

Include these constraints:

- Do not create new Slalom logos, sub-brands, partner lockups, colors, fonts, or official brand assets.
- Do not redraw or reinterpret the Slalom mark.
- Use only existing approved slide renders or neutral placeholders supplied in the source set.
- Treat output as internal inspiration and critique material.
- Preserve confidentiality: do not expose client-sensitive content outside the local workspace.
- Focus on layout, hierarchy, density, rhythm, and visual meaning.

## Visual World Board

Prompt:

Create an internal Slalom HTML deck visual-world board from the supplied slide renders. Organize the board into a clean contact-sheet grid showing covers, executive claims, solution models, proof strips, governance tables, roadmaps, and closes. Emphasize visual rhythm, whitespace, hierarchy, and how Slalom Blue anchors the system. Do not invent new brand assets or alter the Slalom mark.

## Pattern Comparison Board

Prompt:

Create an internal pattern-comparison board from the supplied slide renders. Group slides by communication job: executive claim, solution architecture, operating model, lifecycle flow, governance matrix, roadmap, evidence board, workshop artifact, and executive close. Add short labels naming the pattern and what each pattern is good for. Do not copy client content into new claims; focus on visual pattern learning.

## Style Lens Board

Prompt:

Create an internal style-lens board from the supplied slide renders. Show how the same Slalom brand can flex across four modes: minimalist executive, solution-oriented, high-energy HTML, and tactical operational. Keep Slalom palette, typography, logo, and footer behavior consistent. Show differences through whitespace, hierarchy, density, motion notes, and structural composition, not through new brand identities.

## Redesign Audit Board

Prompt:

Create an internal redesign-audit board that contrasts strong slide patterns with common generic generated-slide failures. Show examples of strong hierarchy, meaningful visual structure, and varied rhythm alongside annotated anti-patterns such as three equal cards, repeated hub-spoke diagrams, fake dashboards, crowded covers, unprioritized tables, and decorative gradients. Do not use external brand references.
