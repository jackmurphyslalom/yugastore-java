# Pattern Gallery

Use these patterns as reusable slide jobs. Pick patterns by communication need, not by visual preference.

## Executive Claim

Use when one idea must land quickly.

Shape:

- large claim headline
- minimal support
- optional proof strip, metric, or quote
- strong whitespace

Best with: `minimalist-executive`, `high-energy-html`

Avoid: turning the slide into a paragraph summary.

## Solution Architecture

Use when explaining how a solution fits together.

Shape:

- layers, modules, flows, or platform stack
- clear system boundaries
- named handoffs
- one focal path or highlighted layer

Best with: `solution-oriented`, `tactical-operational`

Avoid: boxes that only list nouns.

## Operating Model

Use when showing how work is governed and run.

Shape:

- loops, roles, ceremonies, decisions, feedback
- human ownership made explicit
- AI/tooling shown as leverage, not owner
- throughput or quality signal where relevant

Best with: `solution-oriented`, `tactical-operational`

Avoid: method walls and generic process diagrams.

## Lifecycle Flow

Use when showing movement across phases or the full lead-to-cash / delivery lifecycle.

Shape:

- left-to-right rail, loop, or path
- stage gates and decision moments
- evidence and risk markers
- value accumulation toward the end state

Best with: `solution-oriented`, `high-energy-html`

Avoid: flat timelines where every phase is equal.

## Governance Matrix

Use when accountability, decisions, and signals must be explicit.

Shape:

- 3-5 rows
- 3-4 columns
- row labels in blue
- short verb-led cells
- visible ownership and escalation logic

Best with: `tactical-operational`, `solution-oriented`

Avoid: tiny paragraph cells and unprioritized compliance tables.

## Roadmap

Use when showing implementation or mobilization.

Shape:

- now / next / later or wave structure
- current focus highlighted
- dependencies or stage gates
- outcome labels, not activity dumps

Best with: `solution-oriented`, `minimalist-executive`

Avoid: task calendars pretending to be strategy.

## Evidence Board

Use when synthesizing research, discovery, workshop inputs, or current-state signals.

Shape:

- grouped evidence clusters
- source or confidence markers
- one highlighted implication
- clear distinction between observed fact and recommendation

Best with: `tactical-operational`, `minimalist-executive`

Avoid: sticky-note decoration with no synthesized point.

## Pursuit Cover

Use for proposal, POV, or client-facing title slides.

Shape:

- template-grounded title geometry
- approved logo behavior
- color bar where appropriate
- optional client/partner logo slot only when asset is supplied
- optional small semantic preview

Best with: all lenses

Avoid: landing-page hero composition.

## Workshop Artifact

Use when the slide is meant to be worked from, not only presented.

Shape:

- visible sections for input, decision, owner, status, or next step
- enough density to be useful
- strict label hierarchy
- clear writable/readable areas

Best with: `tactical-operational`, `solution-oriented`

Avoid: over-polishing away the operational utility.

## Executive Close

Use when the deck needs a decision or action.

Shape:

- dark or strong reset field
- one ask
- 2-4 commitments or next steps
- optional playbook or scale implication

Best with: `minimalist-executive`, `high-energy-html`

Avoid: ending with a generic "Thank you" unless the deck's channel requires it.
