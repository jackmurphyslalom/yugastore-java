# Style Lens: Minimalist Executive

Use this lens when the deck should feel sparse, editorial, leadership-ready, and restrained.

Best for:

- executive POVs
- leadership updates
- strategy readouts
- decision memos
- high-stakes opening or closing sections

## Design Read

This lens reads as a Slalom executive presentation with quiet confidence: fewer objects, sharper claims, more whitespace, and visual emphasis through proportion rather than decoration.

## Visual Rules

- Use mostly white canvas.
- Let the claim headline dominate.
- Use Slalom Blue as selective emphasis, not as filler.
- Use one secondary accent family only when it adds meaning.
- Prefer thin rails, dividers, proof strips, and precise spacing over cards.
- Keep icons minimal or omit them.
- Keep support copy short and subordinate.

## Layout Moves

- large claim plus proof strip
- white-field reset with one visual anchor
- sparse roadmap with one highlighted stage
- quote or editorial statement with restrained evidence
- governance summary reduced to 3-4 decisive points

## Typography And Hierarchy

- Use sentence-case claim headlines.
- Keep headline wraps intentional; avoid long 5-6 line title blocks.
- Use small caps only for metadata and short eyebrows.
- Use body copy sparingly and keep line length controlled.

## Avoid

- warm beige editorial palettes that override Slalom white and blue
- generic three-card feature rows
- heavy shadows, glass panels, or decorative gradients
- dense icon grids
- long paragraphs dressed up as slides
- stock-image atmosphere with no decision value

## QA

Before finalizing, ask:

- Does the slide still say enough to be useful in an executive room?
- Did whitespace increase hierarchy, or did it remove needed proof?
- Is Slalom Blue doing a job?
- Could the main point be understood in five seconds?
