# Design Critique

Run this critique before final rendering. The goal is not decoration; the goal is visual communication.

## Slide-Level Critique

For each slide, answer:

- What is the one job of this slide?
- What relationship is the visual form encoding: sequence, contrast, hierarchy, system, priority, rhythm, or emotion?
- Could the audience understand the main point from the visual structure before reading all text?
- Is there a clear focal point?
- Is supporting text subordinate to the visual argument?
- Is any visual element merely decorative?
- Does the slide follow Slalom brand rules for color, type, logo, icons, and footer?

Revise if a slide is just text in boxes, unless the slide is deliberately a simple readout or legal/reference page.

## Deck-Level Critique

Review the deck as a sequence:

- Does the deck have a coherent design language?
- Do slide types vary enough to avoid sameness?
- Are reset slides placed where the audience needs a chapter break?
- Does density match the audience and moment?
- Are visuals reused intentionally, or accidentally repeated?
- Does each section have a recognizable rhythm: frame, argue, prove, synthesize?
- Are there enough visual synthesis moments, not just detail pages?

## Revision Rules

- If a slide has many equal-weight boxes, introduce hierarchy: focal node, highlighted path, or grouped clusters.
- If a slide lists phases, turn it into progression, roadmap, swimlane, or maturity movement.
- If a slide compares states, choose a contrast move beyond default mirrored columns when the deck already uses columns heavily.
- If a slide explains a system, show dependencies, flows, or layers instead of a noun map.
- If a slide is dense but necessary, use labels, bands, and spatial grouping so readers can scan it.
- If the deck feels too uniform, vary scale: one dense slide, one synthesis slide, one reset, one proof slide.

## Final Gate

Do not call the deck ready until:

- Visual form carries meaning on the important slides.
- The deck-level language is coherent.
- Repeated primitives are varied.
- Brand rules still hold.
- Rendering and structural QA pass.

## Lens QA

If a style lens from `../slalom-deck-brandkit/` was selected, answer:

- Did the selected lens change layout, hierarchy, density, motion, or rhythm in a visible way?
- Did the lens preserve Slalom palette, typography, logo, footer, cover, and approved asset rules?
- Did the deck avoid obvious starter-primitive repetition?
- Did the lens improve the slide's meaning, not just its decoration?
- If the lens did not materially improve the output, what revision was made before final delivery?
