# Content Intents

Use this file to decide what a slide or deck needs to do before choosing a layout. Start with business/content intent, then choose from several visual moves. Do not map an intent to one fixed slide.

## Design Signal Check

Proceed without asking when the prompt or source material makes these clear:

- Audience: executive, client team, working team, internal enablement, technical audience, or broad mixed audience.
- Purpose: decide, persuade, orient, teach, synthesize, plan, compare, or create alignment.
- Artifact type: proposal, meeting readout, workshop artifact, executive brief, roadmap, delivery plan, enablement deck, or visual explainer.
- Source density: sparse narrative, medium synthesis, dense workshop material, detailed technical inputs, or data-heavy evidence.

Ask 1-3 pointed questions only when the missing signal would materially change the design language. Prefer natural questions:

- "Who is this for, and what decision or action should it move?"
- "Should this feel more like an executive proposal, working-session artifact, sales narrative, internal enablement deck, or something else?"
- "How much density can this audience handle before the slides stop being useful?"
- "Should the story feel more structured and analytical, more visual/story-led, or balanced?"

Do not ask users to choose colors, fonts, logo behavior, footer treatment, or basic brand mechanics unless they request a departure from the Slalom brand contract.

## Deck-Level Design Language

Before creating slides, set a compact design language:

- Structure family: journey, layered system, modular blocks, ecosystem, evidence board, editorial narrative, or mixed.
- Density: executive-readable, sales-polished, workshop-dense, technical/detail-rich, or mixed.
- Visual rhythm: argument slides, proof slides, reset slides, synthesis slides.
- Visual treatment: line diagrams, icon systems, modular blocks, image-led moments, simple charts, or abstract branded diagrams.

Use this as a coherence guide, not a cage. Adjacent slides should not repeat the same geometry unless repetition is part of the story.

Use `../slalom-deck-brandkit/README.md` when the user asks for a specific visual mode or when the deck risks becoming generic. Pick one primary lens and keep Slalom brand rules authoritative.

## Intent Catalog

### Orient And Frame

Use when the audience needs the map before the argument: agenda, section framing, framing questions, read-me labels, content taxonomy, or issue landscape.

Useful moves:

- Contents map with section anchors.
- One-line principle or frame with supporting tags.
- Icon index or labeled visual menu.
- Section divider with strong reset.
- Structured read-me box with status, caveat, or usage label.

Avoid: dense paragraphs pretending to be an agenda, decorative section slides that do not clarify the next chapter.

### Make An Executive Claim

Use when a slide needs to land one strong message.

Useful moves:

- Large claim plus proof strip.
- Metric and implication.
- Quote or editorial statement with restrained supporting evidence.
- Blue-field or white-field reset with one key takeaway.

Avoid: multi-bullet summary slides with no hierarchy, oversized numbers without a point.

### Compare And Decide

Use when the audience must understand tradeoffs, current/future states, options, maturity levels, or criteria.

Useful moves:

- Mirrored columns.
- Spectrum or tension line.
- Criteria matrix.
- Before/after journey.
- Tradeoff cards with one highlighted recommendation.
- Risk/value or impact/effort placement.

Avoid: using the same two-column comparison repeatedly, tables with no visual priority.

### Explain Systems

Use when the slide needs to show relationships, layers, ecosystems, architectures, or value chains.

Useful moves:

- Radial ecosystem.
- Layer stack or pyramid.
- Capability map.
- Flow across systems.
- Cluster map with annotated relationships.
- Modular blocks that show fit and dependencies.

Avoid: architecture boxes that only list nouns, unlabeled circles that do not explain relationships.

### Sequence And Roadmap

Use when showing time, maturity movement, journey phases, project waves, or transformation paths.

Useful moves:

- Horizontal roadmap.
- Staged path.
- Milestone band.
- Maturity ladder.
- Swimlane by workstream.
- Now/next/later progression.

Avoid: timelines with every activity at equal weight, roadmaps where phase labels carry all meaning.

### Operate And Deliver

Use for delivery approach, governance, roles, methods, ceremonies, staffing, or workplan slides.

Useful moves:

- Operating rhythm bands.
- Role/capability matrix.
- Delivery loop.
- Workstream swimlanes.
- Phase cards with activities and outcomes.
- Team topology.

Avoid: method slides that become walls of process text, staffing slides with no relationship between roles.

### Humanize And Storytell

Use when the deck needs empathy, persona grounding, client context, quotes, moments that matter, or an emotional reset.

Useful moves:

- Persona card with context and tensions.
- Day-in-the-life path.
- Quote field.
- Moment map.
- Before/after narrative.
- Photo or illustration-led slide when approved assets are available.

Avoid: generic stock-image decoration, persona slides that do not change the decision.

### Reset And Cover

Use for covers, dividers, background moments, and high-energy chapter changes.

Useful moves:

- Template-grounded cover.
- Blue-field divider.
- Bold editorial statement.
- Branded abstract background.
- Full-bleed approved image with short headline.
- Minimal section title with color bar or line accent.

Avoid: web-hero panels on template-based covers, decorative complexity that competes with the chapter signal.
