# Thumbnail Index

These low-resolution contact sheets are packaged reference boards. Use them for inspiration and critique, not for exact copying. They are intentionally grouped by business/content intent so agents start from the slide's job before choosing a visual move.

Do not assume the source deck is available. These images and notes are the packaged source of design inspiration.

## How To Use

1. Identify the slide or section intent in `content-intents.md`.
2. Open the matching thumbnail group only when the design direction needs visual inspiration.
3. Notice composition, density, rhythm, and visual relationships.
4. Draft a new slide that uses the relevant move without cloning one thumbnail.
5. Run `design-critique.md` before rendering.
